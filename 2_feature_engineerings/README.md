# 2_feature_engineerings

このディレクトリでは、YouTubeトレンド動画データから有効な特徴量を作り、モデル学習に活かすための実験をまとめています。  
主な目的は、タイトル・タグ・カテゴリ・チャンネル情報などをもとに、likes予測や特徴量の有効性を検証することです。

## 目的

- 既存の動画メタデータから、機械学習モデルに投入しやすい特徴量を作る
- タイトル・タグ・カテゴリ・チャンネルごとの傾向を分析する
- どの特徴量が likes 予測に効くかを確認する

## 使用データ

- 主要入力: `english_titles.csv`
- 各サブディレクトリで、必要に応じて追加の中間データや出力ファイルを生成します

## ディレクトリ構成

### 1. category_stats
- カテゴリごとの likes / views / dislikes の平均・中央値を集計
- カテゴリ単位の傾向把握に利用

### 2. channel_avg_views
- チャンネルごとの平均再生回数を集計
- チャンネルの規模感や人気度を把握するための特徴量作成に関係

### 3. title_length
- タイトルの文字数分布を集計・可視化
- タイトルの長さが投稿内容や人気にどう影響するかを確認

### 4. word_freq_analysis
- タイトル・タグに含まれる単語の出現頻度を分析
- 単語ベースの特徴量設計の基礎となる実験

### 5. tag_weighted_title_score
- タグの出現頻度に基づいて、タイトル単語に重み付けを行う
- レアな語を重視したタイトルスコアを作成

### 6. likes_model
- likes予測のための機械学習モデル実験
- LightGBMなどを用いた回帰モデルの学習・評価を行う

### 7. likes_rf_genre_log
- likes予測に関する追加の実験・比較検証用ディレクトリ
- ルールベース・モデル比較・ジャンル/粒度の影響分析に関係する内容が含まれる

### 8. sentiment_analysis
- タイトルや説明文の感情傾向を分析するための実験
- テキスト特徴量の追加候補として利用

## 実験の流れ

1. まず各種統計・頻度分析で特徴量候補を作る
2. タイトル・タグ・カテゴリ・チャンネルの特徴量を整理する
3. その特徴量を用いて likes 予測モデルを試す
4. モデル結果と特徴量重要度をもとに、どの特徴量が有効かを評価する

## 実行のポイント

- 実行は基本的に `info-dm-g5/2_feature_engineering/（各実験ディレクトリ）` から行う
- まずは `likes_model` などのモデル実験と、`title_length` / `word_freq_analysis` などの前処理系実験を順に確認すると理解しやすい

## まとめ

このディレクトリは、YouTube動画のメタデータから「どんな特徴量が予測精度向上に寄与するか」を探索するための実験基盤です。  
特徴量エンジニアリングの段階を通じて、モデルに入れる前の情報整理と、予測性能の比較検証を行うことを目的としています。
