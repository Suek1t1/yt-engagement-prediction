# 3_title_feature_engineering

このディレクトリでは、YouTube動画のタイトル情報を特徴量として扱い、機械学習モデルでどの程度予測性能に寄与するかを検証する実験をまとめています。

## 目的

- タイトルテキストを数値特徴量に変換する
- その特徴量を用いて likes 予測モデルを学習する
- 埋め込み特徴量と英語タイトルベースの特徴量の違いを比較する

## 使用データ

- `datasets/english_titles.csv`
  - タイトル・タグ・メタ情報を含む前処理済みデータ
- `datasets/embedding_features_20.csv`
  - タイトルの埋め込み特徴量（20次元）
- `datasets/embedding_features_50.csv`
  - タイトルの埋め込み特徴量（50次元）

## 実験内容

### 1. タイトル埋め込み特徴量による予測
- タイトル文を埋め込みベクトルに変換し、特徴量として利用する
- 低次元・高次元の埋め込みを比較し、どの次元数が有効かを確認する

### 2. 英語タイトルベースの特徴量による予測
- タイトル文字列を前処理し、英語タイトルの統計・構造的特徴を利用する
- 文字列の特徴量と埋め込み特徴量の違いを比較する

## スクリプト

### `codes/random_forest_embeddings.py`
- 埋め込み特徴量を用いて Random Forest モデルを学習する
- 予測精度や特徴量の扱いやすさを確認するための実験スクリプト

### `codes/random_forest_english.py`
- 英語タイトル由来の特徴量を用いて Random Forest モデルを学習する
- 埋め込み特徴量との比較に向けた実験スクリプト

## 出力・結果

- `figures/`
  - 実験結果の可視化画像を保存するディレクトリ
- `datasets/`
  - 特徴量データや前処理済みデータを格納する

## 実験のポイント

- タイトルの意味内容を埋め込みで捉える方法と、文字列そのものの特徴を利用する方法を比較する
- どちらが likes 予測においてより有効かを確認する
- テキスト特徴量をモデルに取り込む際の基礎実験として位置づけられる

## まとめ

このディレクトリは、タイトル情報を特徴量として利用するための実験を行うための場所です。  
埋め込み特徴量と英語タイトルベースの特徴量を比較することで、テキスト特徴量の有効性とその限界を把握することを目的としています。
