# サムネイルに写っているものを特定する

- **データセット作成担当:** 末吉良多 (245429H)
- **特徴量エンジニアリング担当:** 西銘健汰 (235703J)

Vision-Transformer (ViT) を用いた分析に加え、サムネイル内の文字、被写体、人物情報からも高評価数を予測できるのではないかと考え、Google Cloud Vision API を活用した分析および特徴量抽出を行うこととしました。

---

## 1. データセット作成

### 0. テスト段階
Google Cloud Vision API を用いて、画像内のオブジェクト検出、ラベル検出、および OCR による文字認識の動作確認を実施しました (`test.py`)。

---

### 1. Vision API による解析とデータセット構築
`thumbnail_features_1000.csv` に記載されているサムネイル画像を Google Cloud Vision API で解析し、OCR（文字検出）、ラベル検出、および Web 検出の結果を取得して CSV ファイルとして保存しました (`vision.py`)。

* **生成データセット:** `thumbnail_features_1000.pkl`

---

### 2. クラスタリング手法の検討
はじめは精度の高さを重視して「手動によるクラスタリング」を検討しました。しかし、ラベル数が多くなると手動での分類には限界があるため、「100件程度であれば手動、それ以上は k-means 法による自動クラスタリングで代替する」という方針を立てました。

そこで、検出されたユニークなラベルの総数を集計しました。

* **ユニークなラベルの総数:** 1,145 種類

> [!NOTE]
> ラベルの数が 100 件を大きく上回っていることが判明し、手動での分類は現実的ではないという結論に至りました。
