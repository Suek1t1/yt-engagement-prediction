# 1_first_experiments

このディレクトリでは、YouTube動画データを使って、likes予測に向けた最初の基礎実験を行っています。  
まずは、likesと他の特徴量の関係を可視化し、その後に単純な回帰モデル・ランダムフォレストモデルで予測精度を確認する流れです。

## 目的

- likesがどの特徴量と強く関係しているかを確認する
- 単純な回帰モデルと非線形モデルの違いを比較する
- 予測問題としての難しさを早い段階で把握する

## 使用データ

- `datasets/USvideos.csv - Sheet1.csv`
  - YouTube動画のメタデータを含むデータセット

## 実験内容

### 1. 散布図による関係確認
- `likes` と `views`、`dislikes`、`comment_count` の関係を可視化
- どの特徴量が likes に強く影響しそうかを確認する

### 2. 線形回帰による予測
- `views`、`dislikes`、`comment_count` を説明変数として、likesを予測する
- 基本的な線形モデルの性能を評価する

### 3. ランダムフォレストによる予測
- 数値特徴量を使って、非線形モデルの性能を評価する
- 線形回帰との違いを比較する

### 4. カテゴリごとの散布図の可視化
- `category_id` ごとに views と likes の関係を描画し、カテゴリ間差異を確認する

## スクリプト一覧

- `codes/likes_vs_others.py`
  - likes と views / dislikes / comment_count の散布図を描画
- `codes/dislikes_vs_views.py`
  - dislikes と views の関係を可視化
- `codes/liner_resgression.py`
  - 線形回帰モデルによる予測と評価
- `codes/random_forest.py`
  - ランダムフォレスト回帰モデルによる予測と評価
- `codes/zoom-plot.py`
  - views-likes の散布図を拡大して可視化

## 実験のポイント

- まずは単純な特徴量だけでどこまで予測できるかを試す
- 直線的な関係だけでなく、非線形な関係も考慮する
- ここで得られた知見をもとに、後続の特徴量エンジニアリングへ発展させる

## まとめ

このディレクトリは、YouTube動画データを用いた予測タスクの初期実験をまとめた場所です。  
可視化とモデル比較を通して、どの特徴量が有効かを探索し、後続の高度な特徴量設計へつなげることを目的としています。
